# dsh-cinematography · 电影运镜与镜头语言参考

纯 Node 实现，无网络、无外部服务。

## 安装

```bash
dsh plugin add dsh-cinematography
```
安装后在 profile 的 `package.json` 的 `dsh.profile.bundles` 中加入 `"dsh-cinematography"`。

## 安装

```bash
dsh plugin add github:uckkk/dsh-cinematography
```

> 安装即在本机运行第三方代码，请自行审阅源码。
